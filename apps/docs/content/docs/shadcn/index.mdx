## Prerequisites

Install these prerequisites in your project:

- [Better Auth](https://www.better-auth.com/docs/installation)
- [shadcn/ui](https://ui.shadcn.com/docs/installation)
- [Sonner](https://ui.shadcn.com/docs/components/sonner)

## Installation

<Steps>
<Step>
### Install the auth components

Install the authentication page components with the shadcn CLI.

<include>../../shared/ui/installation/shadcn.mdx#shared-auth</include>

<include>../../shared/ui/index.mdx#shared-install-the-auth-components</include>

</Step>
<Step>

<include>../../shared/ui/index.mdx#shared-install-settings-and-user-button-optional</include>

```npm
npx shadcn@latest add @better-auth-ui/settings @better-auth-ui/user-button
```
</Step>
<Step>
### Install everything (optional)

To install all components, plugins, and email templates, run this command:

```npm
npx shadcn@latest add @better-auth-ui/all
```
</Step>
</Steps>
