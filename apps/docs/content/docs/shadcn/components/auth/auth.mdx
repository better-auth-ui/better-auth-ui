### Built-in views

| `view` | Default path |
| --- | --- |
| `redirect` | `/auth/redirect` |
| `signIn` | `/auth/sign-in` |
| `signUp` | `/auth/sign-up` |
| `signOut` | `/auth/sign-out` |
| `forgotPassword` | `/auth/forgot-password` |
| `resetPassword` | `/auth/reset-password` |
| `resetLinkSent` | `/auth/reset-link-sent` |
| `verifyEmail` | `/auth/verify-email` |

Registered plugins can contribute more views through their own `viewPaths.auth`, such as `magicLink` and `magicLinkSent`.

## Installation

```npm
npx shadcn@latest registry add @better-auth-ui=https://better-auth-ui.com/r/{style}/{name}.json
```

```npm
npx shadcn@latest add @better-auth-ui/auth
```
