---
title: requestPhoneNumberPasswordResetOptions
description: Create a Solid mutation that sends a phone password-reset code.
---

Configure Better Auth `sendPasswordResetOTP` before exposing this action.

## Options factory

```tsx
import {
  type PhoneNumberAuthClient,
  requestPhoneNumberPasswordResetOptions,
  useAuth
} from "@better-auth-ui/solid"
import { createMutation } from "@tanstack/solid-query"

const { authClient } = useAuth()
const requestReset = createMutation(() =>
  requestPhoneNumberPasswordResetOptions(
    authClient as PhoneNumberAuthClient
  )
)

requestReset.mutate({ phoneNumber: "+12025550123" })
```
