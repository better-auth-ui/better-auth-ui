---
title: signInEmailOtpOptions
description: Complete passwordless sign-in with an emailed code.
---

Requires the Better Auth email-OTP plugin. If TypeScript cannot infer the plugin methods from your client, type or cast `authClient` as `EmailOtpAuthClient` from `@better-auth-ui/core/plugins/email-otp`.

Refetches the session on success. Send the code with `sendVerificationOtpOptions` first.

## Options factory

```tsx
import { signInEmailOtpOptions } from "@better-auth-ui/core/plugins/email-otp"
import { createMutation } from "@tanstack/solid-query"

const signIn = createMutation(() => signInEmailOtpOptions(authClient))

signIn.mutate({ email: "alice@example.com", otp: "123456" })
```
