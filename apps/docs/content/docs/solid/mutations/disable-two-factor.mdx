description: Turn two-factor off.
---

<include>../../../shared/mutations/plugin-requirements.mdx#shared-two-factor</include>

Refetches the session so `user.twoFactorEnabled` is up to date.

## Options factory

```tsx
import { disableTwoFactorOptions } from "@better-auth-ui/core/plugins/two-factor"
import { createMutation } from "@tanstack/solid-query"

const disable = createMutation(() => disableTwoFactorOptions(authClient))

disable.mutate({ password: "current-password" })
```
