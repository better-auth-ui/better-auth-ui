---
title: approveDeviceOptions
description: Approve a verified device authorization request.
---

Requires `deviceAuthorizationClient()` from `better-auth/client/plugins`. Call this mutation only after the current session has verified and claimed the user code.

## Options factory

```tsx
import { approveDeviceOptions } from "@better-auth-ui/core/plugins/device-authorization"
import { createMutation } from "@tanstack/solid-query"

const approveDevice = createMutation(() => approveDeviceOptions(authClient))

approveDevice.mutate({
  userCode: "ABCD1234"
})
```
