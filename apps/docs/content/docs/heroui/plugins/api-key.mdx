### Register the UI plugin

Pass `apiKeyPlugin()` to `<AuthProvider>`:

```tsx title="components/providers.tsx"
import { AuthProvider } from "@better-auth-ui/heroui"
import { apiKeyPlugin } from "@better-auth-ui/heroui/plugins/api-key" // [!code highlight]

import { authClient } from "@/lib/auth-client"

<AuthProvider
  authClient={authClient}
  plugins={[
    apiKeyPlugin() // [!code highlight]
  ]}
>
  {children}
</AuthProvider>
```

## Components

### `<ApiKeys />`

<ComponentPreview name="heroui-api-keys" />

The `<ApiKeys />` security card is automatically rendered in `<SecuritySettings />` when the plugin is registered. Pass `organizationId` to scope the list and create payload to an organization instead of the signed-in user.

**Usage**

```tsx
import { ApiKeys } from "@better-auth-ui/heroui/plugins/api-key"

<ApiKeys />
```

**Props**
