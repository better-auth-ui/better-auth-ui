title: <AuthRedirect />
description: Require a session before redirecting to a same-origin page or API callback.
---

`<AuthRedirect />` powers the Solid `/auth/redirect` view. It checks the
current session, then continues to the `redirectTo` query parameter.

## Installation

```npm
npx shadcn@latest add https://better-auth-ui.com/r/solid/auth-redirect.json
```

After install, `src/components/auth/auth-redirect.tsx` is app-owned. Route it
through the unified auth component:

```tsx
import { Auth } from "@/components/auth/auth"

export default function AuthPage(props: { path: string }) {
  return <Auth path={props.path} />
}
```
