## Setup

<Steps>

<Step>

<DocVariant name="heroui shadcn">
### Configure the Better Auth server plugin

Add Better Auth's [Anonymous](https://www.better-auth.com/docs/plugins/anonymous) plugin:

```ts title="lib/auth.ts"
import { betterAuth } from "better-auth"
import { anonymous } from "better-auth/plugins" // [!code highlight]

export const auth = betterAuth({
  // ...
  plugins: [
    anonymous() // [!code highlight]
  ]
})
```
</DocVariant>

<DocVariant name="zaidan">
### Configure the Better Auth server plugin

Add Better Auth's [Anonymous](https://www.better-auth.com/docs/plugins/anonymous) plugin:
</DocVariant>

```ts doc-variant="zaidan" title="src/lib/auth.ts"
import { betterAuth } from "better-auth"
import { anonymous } from "better-auth/plugins" // [!code highlight]

export const auth = betterAuth({
  // ...
  plugins: [
    anonymous() // [!code highlight]
  ]
})
```

Run the Better Auth migration command so the user table includes `isAnonymous`:

```bash
bunx @better-auth/cli migrate
```

</Step>

<Step doc-variant="heroui shadcn">
### Configure the Better Auth client plugin

Add `anonymousClient()` to the browser client:

```ts title="lib/auth-client.ts"
import { createAuthClient } from "better-auth/react"
import { anonymousClient } from "better-auth/client/plugins" // [!code highlight]

export const authClient = createAuthClient({
  plugins: [
    anonymousClient() // [!code highlight]
  ]
})
```

</Step>

<Step>

<DocVariant name="heroui">
### Register the Better Auth UI plugin

Pass `anonymousPlugin()` to `<AuthProvider>`:
</DocVariant>

```tsx doc-variant="heroui" title="components/providers.tsx"
import { AuthProvider } from "@better-auth-ui/heroui"
import { anonymousPlugin } from "@better-auth-ui/heroui/plugins" // [!code highlight]

<AuthProvider
  authClient={authClient}
  navigate={navigate}
  plugins={[
    anonymousPlugin() // [!code highlight]
  ]}
>
  {children}
</AuthProvider>
```

```bash doc-variant="shadcn"
bunx --bun shadcn@latest add @better-auth-ui/anonymous
```

## Change the label

<DocVariant name="heroui">
Override the plugin localization when the default wording does not fit your product:
</DocVariant>

```tsx
anonymousPlugin({
  localization: {
    continueAsGuest: "Explore as a guest"
  }
})
```
