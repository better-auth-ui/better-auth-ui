<DocVariant name="heroui shadcn">
The delete-user plugin renders the UI for Better Auth's built-in [account deletion](https://www.better-auth.com/docs/concepts/users-accounts#delete-user) feature. Users can permanently delete their account with a confirmation dialog via the `<DeleteAccount />` card, wrapped by `<DangerZone />` in security settings.
</DocVariant>

<DocVariant name="zaidan">
The copied Solid/Zaidan delete-user components render the danger-zone account deletion UI for Better Auth's built-in [account deletion](https://www.better-auth.com/docs/concepts/users-accounts#delete-user) capability. Register the UI plugin directly from `@better-auth-ui/core/plugins/delete-user` to show `<DangerZone />` in the copied security settings surface.
</DocVariant>

## Setup

<Steps>

<Step doc-variant="heroui shadcn">
### Enable account deletion in Better Auth

[Better Auth core includes account deletion](https://www.better-auth.com/docs/concepts/users-accounts#delete-user). You do not need another plugin.

Enable the feature by setting `user.deleteUser.enabled` to `true`:

```ts title="lib/auth.ts"
import { betterAuth } from "better-auth"

export const auth = betterAuth({
  // ...
  user: {
    deleteUser: { // [!code highlight]
      enabled: true // [!code highlight]
    } // [!code highlight]
  }
})
```

After you enable the feature, the client provides `authClient.deleteUser()`. You do not need a client plugin.

For an OAuth user without a password, provide `sendDeleteAccountVerification`. This callback lets the user confirm deletion by email.

</Step>

<Step>

<DocVariant name="heroui">
### Register the UI plugin

Pass `deleteUserPlugin()` to `<AuthProvider>`:
</DocVariant>

```tsx doc-variant="heroui" title="components/providers.tsx"
import { AuthProvider } from "@better-auth-ui/heroui"
import { deleteUserPlugin } from "@better-auth-ui/heroui/plugins/delete-user" // [!code highlight]

<AuthProvider
  authClient={authClient}
  navigate={navigate}
  plugins={[deleteUserPlugin()]} // [!code highlight]
>
  {children}
</AuthProvider>
```

<DocVariant name="shadcn">
### Install the UI plugin

Run the shadcn CLI to install the danger zone card and the `deleteUserPlugin()` factory into your project:
</DocVariant>

```npm doc-variant="shadcn"
npx shadcn@latest add @better-auth-ui/delete-user
```

<DocVariant name="shadcn">
This drops the following into your codebase:

- `src/lib/auth/auth-plugin.ts`: local `AuthPlugin` typing widener
- `src/lib/auth/delete-user-plugin.ts`: `deleteUserPlugin()` factory
- `src/components/auth/delete-user/danger-zone.tsx`: the danger zone security card
- `src/components/auth/delete-user/delete-account.tsx`: the delete account card with confirmation dialog
</DocVariant>

<DocVariant name="zaidan">
### Enable account deletion in Better Auth

Enable Better Auth account deletion in your server config:
</DocVariant>

```ts doc-variant="zaidan" title="src/lib/auth.ts"
import { betterAuth } from "better-auth"

export const auth = betterAuth({
  // ...
  user: {
    deleteUser: {
      enabled: true
    }
  }
})
```

<DocVariant name="zaidan">
For OAuth users or flows that confirm deletion by email, configure the related Better Auth options. See the [delete-user documentation](https://www.better-auth.com/docs/concepts/users-accounts#delete-user).
</DocVariant>

</Step>

<Step doc-variant="shadcn zaidan">

<DocVariant name="shadcn">

<DocVariant name="zaidan">
### Install the Solid/Zaidan components
</DocVariant>

```npm doc-variant="zaidan"
npx shadcn@latest add https://better-auth-ui.com/r/solid/delete-user.json
```

<DocVariant name="zaidan">
This copies the following files into your project:

- `src/components/auth/delete-user/danger-zone.tsx`
- `src/components/auth/delete-user/delete-account.tsx`
- local dialog, button, card, input, and label primitives under `src/components/ui/**`
</DocVariant>

</Step>

<Step doc-variant="zaidan">

### Register the UI plugin

Import `deleteUserPlugin()` directly from `@better-auth-ui/core/plugins/delete-user` and register it with your copied Solid auth provider:

```tsx title="src/components/providers.tsx"
import { deleteUserPlugin } from "@better-auth-ui/core/plugins/delete-user"
import { AuthProvider } from "@/components/auth/auth-provider"

<AuthProvider
  authClient={authClient}
  plugins={[deleteUserPlugin()]}
>
  {children}
</AuthProvider>
```

When the plugin is registered, the copied `<SecuritySettings />` surface renders `<DangerZone />` automatically.

</Step>

</Steps>
