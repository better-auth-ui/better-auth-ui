<ComponentPage id="sign-in">

<PageSlot name="usage">

The password starts masked. Its localized show/hide button changes only the field presentation, so the submitted password value stays unchanged.

</PageSlot>

<PageSlot name="installation" doc-variant="zaidan">

After install, `src/components/auth/sign-in.tsx` and the copied sign-in files are app-owned. Register plugins such as Username or Magic Link in `AuthProvider` when you want them to alter the sign-in flow.

</PageSlot>

</ComponentPage>
