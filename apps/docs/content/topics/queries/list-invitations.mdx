## Server-side prefetching

<DocVariant name="react">
For server loaders, import from `@better-auth-ui/core/plugins/organization/server`. Pass the Better Auth server instance, signed-in `userId`, and the request params for organization invitations.
</DocVariant>

```ts doc-variant="react"
import { ensureListOrganizationInvitations } from "@better-auth-ui/core/plugins/organization/server"
import { getRequestHeaders } from "@tanstack/react-start/server"

import { auth } from "@/lib/auth"

await ensureListOrganizationInvitations(queryClient, auth, userId, {
  headers: getRequestHeaders(),
  query: { organizationId: "org_123" }
})
```
