## Server-side prefetching

<DocVariant name="react">
For server loaders, import from `@better-auth-ui/core/plugins/organization/server`. Pass the Better Auth server instance and signed-in `userId`. Request headers are forwarded to Better Auth for session-aware calls.
</DocVariant>

```ts doc-variant="react"
import { ensureListUserInvitations } from "@better-auth-ui/core/plugins/organization/server"
import { getRequestHeaders } from "@tanstack/react-start/server"

import { auth } from "@/lib/auth"

await ensureListUserInvitations(queryClient, auth, userId, {
  headers: getRequestHeaders()
})
```
