## Server-side prefetching

<DocVariant name="react">
For server loaders, import from `@better-auth-ui/core/plugins/organization/server`. Pass the Better Auth server instance, signed-in `userId`, and the request params for the organization member list.
</DocVariant>

```ts doc-variant="react"
import { ensureListOrganizationMembers } from "@better-auth-ui/core/plugins/organization/server"
import { getRequestHeaders } from "@tanstack/react-start/server"

import { auth } from "@/lib/auth"

await ensureListOrganizationMembers(queryClient, auth, userId, {
  headers: getRequestHeaders(),
  query: { organizationId: "org_123" }
})
```
