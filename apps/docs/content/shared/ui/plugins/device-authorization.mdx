The requesting device remains responsible for calling Better Auth's `/device/code` endpoint and polling `/device/token`.

</section>

<section id="shared-install-the-better-auth-plugin">

Add the [Device Authorization](https://www.better-auth.com/docs/plugins/device-authorization) plugin to your Better Auth server. Set `verificationUri` to the public route that renders the UI view:

</section>

<section id="shared-server-example">

```ts title="lib/auth.ts"
import { betterAuth } from "better-auth"
import { deviceAuthorization } from "better-auth/plugins" // [!code highlight]

export const auth = betterAuth({
  // ...
  plugins: [
    deviceAuthorization({ // [!code highlight]
      verificationUri: "/auth/device" // [!code highlight]
    }) // [!code highlight]
  ]
})
```

</section>

<section id="shared-install-the-matching-client-plugin">

Add `deviceAuthorizationClient()` to your browser auth client:

```ts title="lib/auth-client.ts"
import { createAuthClient } from "better-auth/react"
import { deviceAuthorizationClient } from "better-auth/client/plugins" // [!code highlight]

export const authClient = createAuthClient({
  plugins: [deviceAuthorizationClient()] // [!code highlight]
})
```

</section>

<section id="shared-options">

## Options

```ts
deviceAuthorizationPlugin({
  // Override the URL segment. Default: "device"
  path: "activate",
  // Match Better Auth's server-side userCodeLength. Default: 8
  userCodeLength: 8,
  localization: {
    approveDevice: "Allow this device?"
  }
})
```

</section>

<section id="shared-code-length">

Keep `userCodeLength` equal to the value passed to Better Auth's server plugin. A mismatched length prevents valid codes from being submitted.

</section>
